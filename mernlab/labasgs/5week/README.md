## create-react-app
1. Install React App using command
    ```bash
    npx create-react-app styledreactapp --legacy-peer-deps
    ```
2. Move into that File Directory adn Install Packages
    ```bash
    npm uninstall react react-dom
    npm install react@18 react-dom@18
    npm install
    ```
3. Install webpack and web-vitals
    ```bash
    npm i webpack
    npm i web-vitals
    ```
4. Run the App using start script
    ```bash
    npm run start
    ```
